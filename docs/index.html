Smooth corners for the web

A normal border-radius corner stops at a point where the curve suddenly starts. A smooth corner eases into the curve, the same shape Figma and iOS use. This library gives you that with one call.

border-radiusThe curve starts abruptly at a point.
smooth-corners-jsThe curve eases in and out.

Install

npm install smooth-corners-js

Or load it straight from a CDN in a plain page:

<script type="module">
  import { enableAutoSmoothCorners } from 'https://esm.sh/smooth-corners-js';
  enableAutoSmoothCorners();
</script>

Quick start

import { enableAutoSmoothCorners } from 'smooth-corners-js';

enableAutoSmoothCorners({ smoothing: 0.6 });

That is all. Every element with a CSS border-radius now has smooth corners, including elements added later. Your stylesheet is unchanged.

Smooth everything

enableAutoSmoothCorners(options?)

Watches the page and smooths each rounded element. Returns a function that stops it and restores every element.

OptionDefaultMeaning
smoothing0.60 is a normal circular corner. 1 is the broadest curve.
minRadius6Elements with a smaller radius are left alone.
const stop = enableAutoSmoothCorners({ smoothing: 0.7, minRadius: 8 });
stop();

Add data-no-smooth to an element to skip it and everything inside it.

What it does to an element

Backgrounds, borders, ring shadows and soft shadows are redrawn to follow the curve. It re-checks on hover, focus, theme changes and resize.

Smooth one element

applySmoothCorners(element, { radius, smoothing? })

import { applySmoothCorners } from 'smooth-corners-js';

const stop = applySmoothCorners(document.querySelector('.card'), {
  radius: 24,
  smoothing: 0.6,
});

This clips the element to the shape and follows its size. It also clips shadows and anything that overflows, so use it for simple elements. Call the returned function to undo it.

Path helpers

Get the shape as an SVG path string and use it anywhere: an SVG <path>, a CSS clip-path: path("…"), or a canvas Path2D.

createSmoothCornerPath(width, height, { radius, smoothing? })

const d = createSmoothCornerPath(320, 200, { radius: 24, smoothing: 0.6 });
element.style.clipPath = `path("${d}")`;

createSmoothRectPath(width, height, radii, smoothing?, originX?, originY?)

The same, with a separate radius for each corner.

const d = createSmoothRectPath(320, 200, { tl: 32, tr: 32, br: 0, bl: 0 }, 0.6);

Limits

The auto mode leaves an element with its normal rounded corners when it cannot smooth it safely: circles and pills, percentage radii, dashed or mixed-colour borders, borders over a background image, inset shadows, and elements with a child sitting in a corner. Pages with a strict Content-Security-Policy may block the inline SVG images it paints, so allow img-src data:. A smoothed corner looks a little rounder than the same radius, so you may want a slightly smaller one. It runs in the browser only.
